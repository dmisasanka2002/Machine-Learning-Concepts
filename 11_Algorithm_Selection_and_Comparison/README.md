# `11_Algorithm_Selection_and_Comparison/` - README
**Stage 11 of 12 · Core tier · Prerequisites: everything in `03_`–`07_` (this folder is a synthesis, not new material)**

Your "Compare Algorithms" ask, realized: instead of learning 30 algorithms
in isolation, this folder puts them head-to-head, on the same real data,
with real measured numbers - not just qualitative claims.

## Files, in reading order
1. `01_how_to_choose_an_algorithm.ipynb` - the flowchart
   (`_assets/algorithm_choice_flowchart.png`) plus a decision table
2. `02_compare_regression_algorithms.ipynb`
3. `03_compare_classification_algorithms.ipynb`
4. `04_compare_clustering_algorithms.ipynb`
5. `05_compare_dimensionality_reduction.ipynb`
6. `06_complexity_cheatsheet.ipynb` - the master Big-O table

## What you should be able to do after this folder
Given a new dataset and problem, pick a short list of 2-3 algorithms
worth actually trying (not "the one true answer" - `07_no_free_lunch.ipynb`
already established there isn't one) and justify the shortlist using both
the flowchart's qualitative reasoning and this folder's measured
benchmark numbers.

## Where this feeds forward
`12_Projects/` - every project should cite this folder's comparison
notebooks when justifying its final algorithm choice, rather than picking
one without comparison.
