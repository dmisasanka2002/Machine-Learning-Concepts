# `10_Responsible_ML/` - README
**Stage 10 of 12 · Core tier · Prerequisites: `09_Interpretability/`, `05_Model_Evaluation/`**

Where bias enters a pipeline, how to measure fairness formally, and why
fairness metrics genuinely conflict with each other (a real
mathematical result, not just a values disagreement).

## Files, in reading order
1. `01_bias_in_ml.ipynb`
2. `02_fairness_metrics.ipynb`
3. `03_robustness.ipynb`
4. `04_reproducibility.ipynb`

## What you should be able to do after this folder
State demographic parity, equalized odds, and predictive parity
precisely as equations, and explain (using the stated impossibility
result) why choosing between them is a policy decision dressed up as a
technical one.

## Where this feeds forward
`12_Projects/` - every project should include a brief fairness/bias
check where the data plausibly involves people (e.g. the classification
project on ad-response data), using the tools from this folder and
`09_Interpretability/` together.
