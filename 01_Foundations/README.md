# `01_Foundations/` - README
**Stage 1 of 12 · Foundation tier · Prerequisites: none (parallel to `00_Mathematics/`)**

Conceptual scaffolding: what ML is, the vocabulary used everywhere else,
the paradigms (supervised/unsupervised/RL/etc.), the end-to-end workflow,
and how to formalize a real-world problem into an ML task. No heavy math
here - this folder is about getting oriented, not deriving anything.

## Files, in reading order
1. `01_what_is_ml.ipynb`
2. `02_ml_terminology.ipynb`
3. `03_learning_paradigms.ipynb`
4. `04_ml_workflow.ipynb`
5. `05_problem_formulation.ipynb`

## What you should be able to do after this folder
Given a one-sentence problem description, state $X$, $Y$ (or note there
isn't one), the paradigm, and the task family - before opening any
algorithm notebook. This is the single skill `05_problem_formulation.ipynb`
is built around, and it's the one most beginners skip, leading to picking
an algorithm before knowing what problem they're actually solving.

## Where this feeds forward
`02_Data/` assumes you already know what kind of $X$/$Y$ you're working
toward; `11_Algorithm_Selection_and_Comparison/01_how_to_choose_an_algorithm.ipynb`
picks up exactly where `05_problem_formulation.ipynb` leaves off.
